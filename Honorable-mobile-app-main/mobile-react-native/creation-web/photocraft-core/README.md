# Noble's PhotoCraft processing core

This is a small, mobile-bounded integration of five real PhotoCraft Rust libraries: geometry, ICC color foundations, color/blend math, tiled raster infrastructure and imaging algorithms. Unchanged upstream production source/data comes from `storytold/photocraft` at `f143ce58498f201a8dfc9c07f5e24147c6a22bee`. `UPSTREAM.json` records each byte hash. Original Cargo manifests are retained separately; production manifests omit upstream-only development/benchmark targets. The Noble adapter exposes twelve bounded filters and five layer blend modes on RGBA working copies up to512px. Ordinary filters/compositing are not AI.

This is **not** the full PhotoCraft application or a claim of Photoshop parity. No desktop UI, logos, branded artwork, fonts, account/network services, arbitrary engine commands, PSD parsing, CMYK editing, high-bit-depth editing or native Apple/Android bridge is included. The core libraries themselves retain their broader upstream types; this deliberately narrow adapter exposes only8-bit sRGB working copies. A synthetic CC0 CMYK profile is an upstream compile-time input, not an Adobe profile or an exposed mobile conversion feature.

Source/code: MIT OR Apache-2.0, with both license texts and upstream NOTICE. Embedded upstream face-detection data/code retains its BSD-3-Clause notice, although this adapter does not expose face detection. The synthetic PhotoCraft ICC profile is CC0-1.0 per upstream ATTRIBUTION.md. Bundled runtime notices live in the parent THIRD_PARTY/PHOTOCRAFT-NOTICES.txt. No proprietary Adobe or Photopea code is used.

Reproduce with Rust1.95.0, its wasm32-unknown-unknown target, and wasm-bindgen-cli0.2.106. From creation-web run `npm run build:photocraft`; NOBLE_CARGO and NOBLE_WASM_BINDGEN optionally point to installed executables, and NOBLE_CORE_TARGET optionally selects a build directory outside this source tree. Cargo uses the committed lockfile. The build records every source/runtime hash and compiler versions; ordinary drawing builds must verify those records before copying the compiled JS/WASM. Build caches, installers, corpora and prototype outputs are not committed.

Adapter tests run with `cargo test --locked -p noble-photocraft-core` from this directory. They cover adversarial bounds/NaN, real inversion/alpha/source retention, alpha compositing and repeated-edge blur. This is not an assertion that the entire upstream test suite ran. Browser/native build/device acceptance must be recorded separately in docs/PHOTOCRAFT_MOBILE_INTEGRATION.md.
