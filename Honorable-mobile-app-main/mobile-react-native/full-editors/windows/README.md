# Noble Studio for Windows

Run the Noble Studio Setup executable to install for your Windows account. Setup adds a Start menu shortcut. Choose **OK** on the completion prompt to open Noble immediately, or **Cancel** to finish with the app closed. If you have the portable ZIP, extract the whole archive and open `NobleStudio.exe`. Browse a chosen folder, search filenames, preview photos and supported videos, and open either editor. Use **Home** on the editor toolbar or **Projects** in the full tools to return. Both editors stay open while you switch workspaces. Save projects before quitting Noble Studio. Folder selection is session-only. To send an exported file to another app, select **Projects > Copy exported file**, choose the file, and paste it in a destination that accepts Windows clipboard files. The bundled offline TinyCLIP model ranks up to 200 photos and 20 supported videos from the selected folder. Videos are ranked by the closest of three sampled frames. For a beginner edit, open Video Studio and choose **Photo storyboard** to set the order and duration before building the timeline. Account workflows still need a Windows implementation.

**Open photos** on Projects opens the selected files in the native PhotoCraft workspace inside Noble Studio. The shortcut opens working copies, so **Save As** lets you choose where to keep an edit. Use **File > Open** in Image Studio when reopening a layered project in place. **Open Image Studio** opens the same workspace without a picker. Its menus, left tool rail, document tabs, canvas, and right-hand panels are PhotoCraft's.

In **AI photo workspace**, drop a photo or layered project onto the canvas. Use **Adjust** for editable light and color layers and **Layers** to select, show, hide, or edit them. **AI tools** previews a local edit and can open an approved copy as a new image. Use **Save project** for an editable `.pcraft` copy and **Export photo** for a PNG or JPEG. This workspace also accepts multiple photos through **Browse files** and opens HEIC and HEIF as local lossless PNG copies.

**Open Image Studio** and **Full video tools** on Projects open inside the Noble window. The installer includes the Windows x64 editor engines from PhotoCraft 0.23.1 and FilmCraft 0.20.1, their command-line programs, and their original notices. Use **Projects** in the Noble toolbar to switch workspaces. Use **Noble AI workspace** to reach the corresponding AI and MCP controls. The full editors and AI workspaces maintain separate editing sessions. Save an editable project before opening it in the other workspace. [PhotoCraft release](https://github.com/storytold/photocraft/releases/tag/v0.23.1) · [FilmCraft release](https://github.com/storytold/filmcraft/releases/tag/v0.20.1)

Open **Workspace** to choose the inspector side and width, control size, theme, or canvas-only view. Settings are saved for the next launch.

In the AI photo workspace's **Agent** tab, describe a global photo edit and select **Plan edit**. The configured local Ollama model requests photo inspection through MCP and proposes layers for brightness, contrast, saturation, warmth, or black and white. **Natural** keeps adjustments within a tighter range based on the photo's existing color and contrast. Choose **Creative** for stronger edits. Compare the original and the rendered preview in the canvas, keep the adjustments you want, and set their strength. The preview flags newly clipped highlights or lost shadow detail. Choose **Apply selected** to add editable layers at the original resolution in one Undo step. Ollama receives sampled tone and color statistics. Start Ollama and install `qwen3:4b` if the Agent tab shows setup instructions.

Open **Tools > Quick draft** in Video Studio to draft or revise a vertical edit from photos and labeled clips. It uses MCP and a separately installed local Ollama service. The default model name is `qwen3:4b`. To select another locally installed model, launch `NobleStudio.exe --model=NAME`. The editor itself can open while Ollama is unavailable.

Open **AI agent** in Video Studio. Select 3–12 supported videos and a music track at least 20 seconds long. Run `ollama pull qwen3:4b` and start Ollama if setup reports a missing service or model. Enter the brief and select **Build first cut**. Preview in the timeline. **Revise middle** creates a faster middle while keeping the opening and closing cuts in place. **Undo agent revision** switches back to the preceding sequence. Save and export using FilmCraft’s normal controls.

Run `codex mcp add noble-studio --url http://127.0.0.1:4184/mcp/desktop` to register or update Noble in local Codex. Keep the **AI video workspace** open and import the footage or music you want Codex to edit. It can inspect shot timing and music beats, build a timeline, duplicate an existing sequence, and edit specific clips. Tools cover trimming, splitting, moving, retiming, keyframed motion, color, transitions, audio mixing, titles, and timed subtitles. Ask Codex to duplicate your sequence first when you want to compare versions.

Edited timelines stay editable in Noble. Native project copies are saved under **Videos / Noble Projects** and reference the imported source files. Finished MP4s appear under **Videos / Noble Exports**. Video MCP tools run without Ollama. To let Codex review imported footage or a rendered frame, open **Tools** in Video Studio and enable frame sharing for that editor session.

For photos, keep Ollama running, open a photo in Image Studio, and ask Codex to use Noble's `preview_photo_edit` tool. The tool prepares a preview and returns the proposed adjustments. Approve them with **Apply selected** in Noble.

The x64 executable is a Windows Forms app. The bundled editor interfaces run in the installed Microsoft Edge WebView2 Runtime. The package includes a headless Node.js service, starts it automatically, and uses a loopback-only endpoint on port 4184. Keep the installed files together. The installer and Noble executable are unsigned. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

For a source build, put `node-v24.22.3-win-x64.zip` and `microsoft.web.webview2.1.0.3595.46.nupkg` into one directory. Build with `build-portable.ps1 -RuntimeDirectory PATH -Stage NEW_PATH -SearchModules NODE_MODULES`. The build checks both release hashes. Use Windows with the .NET Framework 4.8 compiler and an existing Node.js install to build the search worker. [Node.js release](https://nodejs.org/en/blog/release/v24.22.3) · [Microsoft WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3595.46)

For the desktop renderer themes, prepare separate checkouts at the revisions in `../upstreams.json`. Apply the matching patch from `../patches` followed by `filmcraft-desktop-theme.patch` or `photocraft-desktop-theme.patch`. Follow the pinned Rust, wasm-bindgen, and notices steps in `../README.md`. Run `package.mjs` with `--windows-theme` and pass those outputs to `build-portable.ps1 -DesktopVideoBundle VIDEO -DesktopImageBundle IMAGE`. Without those arguments the installer uses the stock renderers. Keep the desktop bundles outside Android's assets directory.

Pass `-NativeArchiveDirectory PATH` to `build-portable.ps1` with the publisher ZIPs named in `native-studios.json` to include the native editors and HEIC decoder. The build verifies the pinned SHA-256 checksums and keeps each portable archive's notices. To package an installer from staging, run `build-installer.ps1 -Stage PATH -Output NEW_SETUP_EXE`. It installs per user under Local AppData and creates a Start menu shortcut. The Noble Setup executable is unsigned.
