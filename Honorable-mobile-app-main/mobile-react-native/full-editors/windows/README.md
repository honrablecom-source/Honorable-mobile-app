# Noble Studio for Windows

Run the Noble Studio Setup executable to install for your Windows account. Setup adds a Start menu shortcut. Choose **OK** on the completion prompt to open Noble immediately, or **Cancel** to finish with the app closed. If you have the portable ZIP, extract the whole archive and open `NobleStudio.exe`. Browse a chosen folder, search filenames, preview photos and supported videos, and open either editor. The **N** at the left of the Video Studio menu bar returns to Projects. The workspace selector is at the right. Use **File > Export > Video (MP4)…** for MP4 delivery, **Tools** for the AI editor and changes, and **Projects > Open… > Full video tools** for the separate native toolset. Both editors stay open while you switch workspaces. Save projects before quitting Noble Studio. Folder selection is session-only. To send an exported file to another app, select **Projects > Copy exported file**, choose the file, and paste it in a destination that accepts Windows clipboard files. The bundled offline TinyCLIP model ranks up to 200 photos and 20 supported videos from the selected folder. Videos are ranked by the closest of three sampled frames. For a beginner edit, open Video Studio and choose **Tools > Photo storyboard** to set the order and duration before building the timeline. Account workflows still need a Windows implementation.

**Image Studio**, **New photo project**, **Open photos**, and recent photos all use one Noble Image Studio session. A new project starts with a white 1920 × 1080 canvas. PhotoCraft’s menus, tool options, tool rail, and document panels are present in the editor. Open **Noble AI** to review adjustments or run a local AI tool alongside that document. The AI panel opens below the canvas. Drag the divider on the comparison image to review the proposed layers. Close the panel to regain canvas height and reopen it to continue the same review. Applying them updates the editor’s layer stack and undo history.

Use **Ctrl+S** for an editable `.pcraft` copy. In the editor’s **File → Export** menu, choose **Export As** to select a format or **Quick Export as PNG** for a PNG copy. The house icon returns to Noble Projects. Workspace settings and Noble AI sit at the bottom of the editor. HEIC and HEIF imports use a bundled local command-line decoder. The integrated file importer accepts up to 12 files at a time, with a 64 MB per-file limit and a 128 MB batch limit through the Windows picker. The image engine and its licenses ship with Noble. The separate PhotoCraft desktop application is excluded.

**Full video tools** opens FilmCraft in the Noble window. Use **Projects** in the toolbar to switch workspaces. The native and AI video workspaces have separate sessions. Save a video project before opening it in the other workspace.

Open **Workspace** to set the comparison image’s position and width, choose a control size or theme, or switch to canvas-only view. Settings are saved for the next launch.

In Image Studio’s **Noble AI > Editing agent** tab, describe a global photo edit and select **Plan edit**. The configured local Ollama model requests photo inspection through MCP and proposes layers for brightness, contrast, saturation, warmth, or black and white. **Natural** keeps adjustments within a tighter range based on the photo's existing color and contrast. Choose **Creative** for stronger edits. Compare the original and the rendered preview in the AI panel, keep the adjustments you want, and set their strength. The preview flags newly clipped highlights or lost shadow detail. Choose **Apply selected** to add editable layers at the original resolution in one Undo step. Ollama receives sampled tone and color statistics. Start Ollama and install `qwen3:4b` if the Agent tab shows setup instructions.

Open **Tools > Quick draft** in Video Studio to draft or revise a vertical edit from photos and labeled clips. It uses MCP and a separately installed local Ollama service. The default model name is `qwen3:4b`. To select another locally installed model, launch `NobleStudio.exe --model=NAME`. The editor itself can open while Ollama is unavailable.

Open **AI agent** in Video Studio. Select 3–12 supported videos and a music track at least 20 seconds long. Run `ollama pull qwen3:4b` and start Ollama if setup reports a missing service or model. Enter the brief and select **Build first cut**. Preview in the timeline. **Revise middle** creates a faster middle while keeping the opening and closing cuts in place. **Undo agent revision** switches back to the preceding sequence. Save and export using FilmCraft’s normal controls.

Run `codex mcp add noble-studio --url http://127.0.0.1:4184/mcp/desktop` to register or update Noble in local Codex. Keep the **AI video workspace** open and import the footage or music you want Codex to edit. It can inspect shot timing and music beats, build a timeline, duplicate an existing sequence, and edit specific clips. Tools cover trimming, splitting, moving, retiming, keyframed motion, color, transitions, audio mixing, titles, and timed subtitles. Ask Codex to duplicate your sequence first when you want to compare versions.

Edited timelines stay editable in Noble. Native project copies are saved under **Videos / Noble Projects** and reference the imported source files. Finished MP4s appear under **Videos / Noble Exports**. Video MCP tools run without Ollama. To let Codex review imported footage or a rendered frame, open **Tools** in Video Studio and enable frame sharing for that editor session.

Connected editors advertise individual MCP tools for their native commands. Call `find_editor_skills` with a studio and a search, for example `{"studio":"photo","query":"canvas size"}`. Results include tool names and argument schemas. Clients that load a limited tool list can use `run_editor_skill` with the returned name and arguments. Direct MCP clients can follow `nextCursor` in `tools/list`.

In Image Studio, start with `get_photo_context`. Pass its `documentId` and `revision` to a skill such as `photo_layer_new_layer` with `parameters: {"name":"Foreground"}`. Use the new revision on the next call. Video skills take the revision from `list_video_media` or the previous edit. Native skills use the current editor and report when a command is disabled by the selection, document mode or timeline state. Interactive commands may open an editor dialog. Use `includeManual: true` in a skill search to also find catalog entries that require Studio.

For a model-planned photo edit, run Ollama and use `preview_photo_edit`. Review the proposed layers, enter their strength as a percentage, and choose **Apply selected** in Noble. Connected AI can also call `set_photo_review_strength` or run individual local previews for cutout, subject color, denoise, neural color and neural painting. Those five preview tools use Noble’s bundled processing and the active photo.

The x64 executable is a Windows Forms app. The bundled editor interfaces run in the installed Microsoft Edge WebView2 Runtime. The package includes a headless Node.js service, starts it automatically, and uses a loopback-only endpoint on port 4184. Keep the installed files together. The installer and Noble executable are unsigned. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

For a source build, put `node-v24.22.3-win-x64.zip` and `microsoft.web.webview2.1.0.3595.46.nupkg` into one directory. Build with `build-portable.ps1 -RuntimeDirectory PATH -Stage NEW_PATH -SearchModules NODE_MODULES`. The build checks both release hashes. Use Windows with the .NET Framework 4.8 compiler and an existing Node.js install to build the search worker. [Node.js release](https://nodejs.org/en/blog/release/v24.22.3) · [Microsoft WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3595.46)

For the desktop renderer themes, prepare separate checkouts at the revisions in `../upstreams.json`. Apply the matching patch from `../patches` followed by `filmcraft-desktop-theme.patch` or `photocraft-desktop-theme.patch`. Follow the pinned Rust, wasm-bindgen, and notices steps in `../README.md`. Run `package.mjs` with `--windows-theme` and pass those outputs to `build-portable.ps1 -DesktopVideoBundle VIDEO -DesktopImageBundle IMAGE`. Without those arguments the installer uses the stock renderers. Keep the desktop bundles outside Android's assets directory.

Pass `-NativeArchiveDirectory PATH` to `build-portable.ps1` with the publisher ZIPs named in `native-studios.json` to include the native video editor and the photo decoder. The build verifies the pinned SHA-256 checksums and keeps each portable archive's notices. To package an installer from staging, run `build-installer.ps1 -Stage PATH -Output NEW_SETUP_EXE`. It installs per user under Local AppData and creates a Start menu shortcut. The Noble Setup executable is unsigned.
