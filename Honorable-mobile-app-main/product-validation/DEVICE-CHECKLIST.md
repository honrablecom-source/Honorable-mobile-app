# Android device check

Use the `honorable-android-debug` APK from the linked Actions run. Record device/Android version and pass/fail for each item. Google Sign-In needs both Actions configuration values and the APK certificate registered for `com.honorablemobile`. Production search completion currently needs a trusted native verifier; do not treat the local web verifier as device verification.

1. Install and open; no crash.
2. Continue with Google; reach Home.
3. Close/reopen; session restores without another sign-in.
4. Open all five tabs.
5. Import the validation photos; search “sunset over a sandy beach”.
6. Successful FAST search deducts exactly 1 credit, free first.
7. Failed/cancelled search deducts nothing.
8. Try V2 video; record actual video/timestamp without assuming success.
9. Pass shows 20 options, then all 31; no real-money purchase enabled.
10. Usage agrees with the account ledger.
11. Open the real found photo → Edit.
12. Adjust and Save As Copy; new image opens.
13. Original image remains unchanged.
14. Logout/relogin; same identity keeps credits; another identity has separate data.
15. V3 stays unavailable and cannot charge.
