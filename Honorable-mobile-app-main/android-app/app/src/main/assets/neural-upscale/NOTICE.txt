Noble bundles the unmodified public ONNX model for a separate local inference session. No private image or query upload is needed. Source/current-image RGB input is normalized to [0,1], symmetrically padded to the next multiple of eight, and reconstructed at twice its dimensions. Separate Kotlin preprocessing/tiling/UI code is not a modification to the model weights.

AI output estimates detail and can change faces, text or patterns; it does not recover guaranteed original information. Review the complete output before sharing. Model authors/converter do not endorse Noble. No accuracy, device performance or fitness warranty. See the full accompanying license.
