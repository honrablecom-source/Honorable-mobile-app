Project → Review sampled dark holds scans the whole selected clip locally, previews every candidate's complete downsampled dark frames and both bright sampled neighbors, starts every removal unchecked, then reviews the complete ripple edit and caption assignments before an owned one-use Apply/preview with Undo. This is a new source-frame content-analysis workflow, distinct from quiet-pause removal, RMS-onset cuts, metadata overlap detection or a frame archive. Original media stays unchanged. Both picture and original audio in chosen intervals disappear from the edit; later footage ripples earlier. Soundtrack settings stay, so synchronization changes.

A 2.5–120 source-second clip receives evenly spaced requested frame centers: ceiling(duration/500ms), capped at64. Sampling is therefore coarser on clips longer than32seconds. MediaMetadataRetriever uses the nearest decoded original frame, bounded to256pixels per edge without upscaling. All pixels must be opaque with each 8-bit RGB channel≤12 to classify a sample DARK; any transparency is UNKNOWN, and any higher channel on opaque samples is BRIGHT. At least3consecutive DARK samples with BRIGHT neighbors on both sides form a candidate. Leading/trailing/unknown-adjacent/short dark runs stay. Proposed removal uses only first-to-last dark requested centers, not the outer sample cells or actual decoded timestamps.

This is experimental sampled dark-content analysis, not proof of empty/black footage. Intentional night/dark scenes, repeated nearest frames, missed bright flashes and downsampling can mislead. No full-resolution, HDR, color-profile, exact decoded-time or codec-frame accuracy claim. Source samples exclude edited titles, captions, grade, crop, motion and fades; meaningful overlays may disappear when a source-dark interval is removed. Every candidate and its bright neighbors are previewed with requested time and classification. Every checkbox starts OFF. The owner must inspect samples, explicitly select intervals, review all resulting source windows/captions/timing and then Apply. Sampling alone changes nothing.
