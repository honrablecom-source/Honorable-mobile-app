# C079 — Remove interior quiet video pauses

**1 new experimental source workflow; 0 separate fixes/scaffolding.** Threshold, pause length, padding and entrypoints are parameters of this one workflow. No APK or device acceptance is claimed.

Video editor → Audio → Remove quiet pauses, also available through the inspector, analyses the selected clip's original audio locally. A review lists proposed source-time cuts and the playback duration removed. Keep current edit cancels; Apply cuts replaces the selected clip with retained pieces and moves later clips earlier. Playback preview opens after Apply. One Undo restores the previous timeline.

This is a short-range energy heuristic, not speech recognition. It reads original audio before clip volume, mute, music and effects, rather than listening to the final project mix. Quiet words or music may be selected. Leading/trailing quiet and unknown audio regions are kept. Review source-time cuts and the resulting playback, captions and mix. Clip settings, source IDs, original source-relative caption timestamps/provenance and other clips are retained. Captions outside retained pieces disappear from playback; spanning cues can occur on both pieces. Existing edge fades apply to new pieces. The separate soundtrack keeps its settings while the video timeline shortens.

## Bounds and implementation

- One readable audio track, selected range at most two source minutes, timestamps within the supported integer-millisecond source range. No audio or multiple audio tracks are refused without an edit.
- Threshold −60 to −15 dBFS; minimum pause 0.2–5 playback seconds; retained edge padding 0–0.5 playback seconds. Speed-aware conversion uses source milliseconds. Twenty-millisecond source windows make this an approximate detector, not sample/frame-accurate speech alignment.
- Supported decoded PCM is signed 16-bit or float, 8–192 kHz and 1–8 channels, with bounded buffers. Channel powers are averaged, avoiding stereo phase cancellation. Nonfinite float samples are refused; finite overshoot is clamped. Preroll/out-of-range samples are excluded, backward/overlapping timestamps refused, and missing/overfull windows marked unknown. Less than 90% known window coverage is refused.
- Only quiet runs surrounded by known louder audio can be cut. Context padding remains at both edges. Fewer than 50 cuts, up to 50 retained pieces, at least 0.1 playback second per retained piece and the existing 1,000-clip project limit are enforced. Existing project caption/text/recovery validators run atomically before the edit is accepted.

`VideoQuietAudio` uses the existing Android framework [MediaExtractor](https://developer.android.com/reference/android/media/MediaExtractor), [MediaCodec](https://developer.android.com/reference/android/media/MediaCodec), [BufferInfo](https://developer.android.com/reference/android/media/MediaCodec.BufferInfo) and [MediaFormat](https://developer.android.com/reference/android/media/MediaFormat) APIs. No production dependency, permission or network service is added. It accepts local content URIs, decodes on a worker, checks a 30-second processing-loop deadline/cancellation and has unconditional output-buffer/codec/extractor cleanup calls. Blocking platform/provider calls cannot be forcibly interrupted; actual vendor timing and cleanup remain untested.

The Activity captures project, clips, selected index, soundtrack, source URI map, mode, namespace and foreground generation. It checks them before starting, before showing results and before Apply. Pause/destroy cancels the job, invalidates its generation and dismisses its dialog. Returning to the same editor cannot make an old proposal current again. Worker failure, cancellation, stale state or project-limit failure leave the edit unchanged. UI preview failure after a successful Apply is reported as an applied edit with Undo available, rather than incorrectly claiming nothing changed.

No original media file is modified or uploaded. Analysis windows are transient; only the normal editable timeline changes after explicit Apply. Native media search/ranking, AI access rules, credit pricing and ledger authority are untouched.
