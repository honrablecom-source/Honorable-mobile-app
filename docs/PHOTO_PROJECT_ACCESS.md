# Photo saved edits reuse current native image access

Zero new features; one core access fix. At publication the shared source count is85/500, batch47 beyond38, including noble-main's separately published C086. This fix adds no feature.

The native photo editor previously checked only broad READ_MEDIA_IMAGES (or legacy storage permission) before saving/restoring editable photo projects. An original opened with selected-photo access could therefore be sent through an unnecessary persistable Files-grant attempt. The editor now delegates current image capability to the existing, unchanged MediaCapabilityManager. Both app manifests already declare selected-photo access; no permissions are added or requested by this change. Native discovery already constructs image item URIs through MediaStore.Images.Media and ContentUris.withAppendedId.

An existing persisted read grant for a content URI still works without consulting library permissions. Otherwise, current image capability is considered only for a strict content://media/{volume}/images/media/{positive Long ID} item. Volumes and IDs are bounded; video, audio, collection, malformed and arbitrary-provider URIs cannot inherit image capability. Nonpersisted documents retain the existing explicit document-grant flow and rollback rules. The success message now says to reopen the same original, since Files is one route and the Library is another.

Capability is a precheck rather than proof that any particular selected item can be read. The existing actual source open, streamed fingerprint, original/owner-bound project codec and guarded store operations remain authoritative. Deleted/revoked/changed originals can still fail; saved metadata is preserved. No capability is cached, broadened or converted into a document grant, and media is not copied/uploaded. This does not promise indefinite permission retention or account synchronization.

[Android selected-photo access guidance](https://developer.android.com/about/versions/14/changes/partial-photo-video-access) describes separate partial capability and advises rechecking access because it can change.
