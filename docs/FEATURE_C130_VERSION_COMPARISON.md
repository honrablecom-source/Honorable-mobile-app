# C130 — Compare a saved video version with current edits

Native video Project tools → Saved video versions → Compare saved version with current reads a chosen saved draft and shows a metadata comparison without opening it. Existing save/open/delete/deletion-Undo actions keep their original indexes and behavior. Compare is appended after those actions; Back to versions reloads the current shelf. Opening remains the existing separate reviewed/validated action.

The comparison is within the same primary-source shelf. Clips are compared by timeline position, not semantic identity or matching footage. Insertion/reordering can mark subsequent positions changed. Every position is counted, but only the first100changed positions are expanded. Added/removed tail positions are reported. Categories cover source binding, original window/speed, title/title appearance, grade, framing, motion, edge fades, source audio and captions/subtitle binding. Each shown position includes current/saved source ID, original range, speed, cue count and title. Full caption text and appearance parameter values are not expanded.

Imported source binding maps include ID, URI and duration; ordering of that catalog alone is ignored. A changed URI under the same source ID is detected without displaying source URI metadata. The report separately compares primary duration, soundtrack settings and working selection/range/playhead, and uses authoritative whole-project microseconds for playback totals. This is metadata inspection: it does not render media, compare picture/audio quality, validate original availability or promise export equivalence. The current draft and saved version remain unchanged; no Undo edit is created.

The existing private shelf worker owns the operation. Exact current entry identity is re-read through `requireEntry` before decoding/comparing. Current account ownership is checked before/after work; existing full foreground/session/project state gates the UI result. A closed/cancelled/stale/foreign stage cannot navigate or publish another comparison. Displayed report text clears on dismissal. No provider probing, permission acquisition, clipboard action, edit application, catalog save/delete or media upload is part of comparison.
