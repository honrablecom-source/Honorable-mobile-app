## Outcome

## Core release acceptance

- Search: preserve the native on-device engine/ranking, original media privacy, indexing/permission/cancellation/error behavior and existing V1/V2/V3/credit/ledger rules. Never inspect Seran holdout or run its expensive benchmark.
- Photo: import/create, crop/color/text/layers, undo/recovery and save-copy export. Make actual AI subject/background tools, neural upscale and OCR editing/privacy discoverable; correct model errors through review rather than automatic destructive edits.
- Video: import/create, preview/timeline/trim/music/titles, undo/recovery and video/audio export. Expose actual local speech captions, caption translation, visible-text recovery and sound captions with download consent, correction and source protection.
- Creation/animation/color/texture/modeling: reuse suitable established open-source engines, adapting touch UI, bounded media/state, persistence and real exports. Existing Excalidraw is already bundled. Audit and integrate a useful mobile creative workspace instead of recreating a large desktop suite. Distinguish actual AI inference from ordinary animation/modeling controls; no fake generators or unsupported category claims.
- UI: prioritize search, photo, video and creation with clear AI entry points. Keep white-majority surfaces, black/gray controls, accessible touch targets and original media colors; reduce clutter and misleading availability.
- Validation: install exact lockfiles; run Node, drawing, React Native typecheck/lint/Jest, native tests/compilation and current whole-app build. Retain full failures, fix causes and report remaining scope accurately. Verify packaged JS/local models/drawing assets and signing/ABI identity.
- Artifacts: remove the explicitly obsolete tracked APKs and stale release claims; create fresh self-contained Android tester APKs and appropriate ABI/release artifacts. Public debug signing is internal only. Build current iOS on macOS CI where available; simulator app/unsigned device archive/signed IPA are separate deliverables. Native iOS search/editing is currently absent and must not be hidden behind a successful shell compile.
- Publication: continue owner-authorized commits/pushes through one Noble Chat publishing owner. Do not commit private media, credentials, signing material or tool caches. Both chats work solo without spawned agents/computer use and claim file scopes before edits.
