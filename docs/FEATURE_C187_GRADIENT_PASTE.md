The residual is measured before channel clipping and byte rounding. `solutionErrorBound = maximumResidual * min((patchWidth+1)^2,(patchHeight+1)^2)/8`: a discrete rectangular barrier bounds raw floating solution error. Near exact half-byte ties, a solver approximation can round one byte differently from a dense solution; oracle checks permit that only when its certified interval reaches the half tie. It is not permission for arbitrary one-byte differences. Clipped output cannot be described as an exact unconstrained Poisson solution.
