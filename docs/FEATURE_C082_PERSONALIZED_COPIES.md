# C082 — Personalized editable design copies

**1 new experimental source workflow; 0 separate fixes/scaffolding.** Make differently personalized copies from one selected design using local tab- or pipe-separated rows. This is distinct from identical grid repeats and single starter-design personalization. Copies, fields, columns and text-size parameters are not additional features.

In Drawing, edit variable text to include fields such as `Hi {{name}}`, select the design, then Arrange → Personalized copies. Paste a header row followed by values, choose copies per row and Preview. Review the image and value rows, then Insert or discard the preview. The source stays unchanged. Each value row becomes an independently editable group beside the drawing; one Undo removes the entire batch. Existing PNG, SVG and editable-project exports handle the result.

## Boundaries and implementation

- Local input: up to8,192UTF-16 characters,1–8 unique ASCII field names,1–24 value rows,64Unicode code points per cell. Names are case-sensitive; whitespace is trimmed. Paste tabs or separate columns with `|`; quoted CSV is not supported. Values are single-line literal text. C0/C1 controls, Unicode line separators, malformed surrogate pairs, missing columns and incomplete template fields are refused. Formula-looking text, dollar signs, braces and HTML-looking text are not executed or recursively expanded.
- `personalize.mjs` reuses the existing complete-component graph and project-merge logic. Templates include attached text/frame children and detach outside references under the existing capture contract. Up to100 source objects; hidden template artwork and locked field text/containers are refused. Every row gets fresh object/group IDs and independent reciprocal bindings. Embedded photos retain the same immutable content IDs and bytes; no extra source photo file is created.
- `personalize-text.mjs` uses pinned Excalidraw0.18.1 wrapping/measurement through its public restore API. Changed text wraps and can shrink to8pixels within bounded source boxes; unfit values fail the whole preview. Raw `originalText` is retained. Typography yields between fields and checks request ownership. Cell dimensions use the maximum prepared bounds, with32units between copies; existing artwork is retained to the left.
- `PersonalizeTool` provides preview, used-field feedback, a full row review, discard and explicit insertion. Closing or editing input invalidates pending work. Source publication checks the same editor, full document snapshot, current selection and preserved-draft/busy guards. The existing durable-before-render publication path validates the whole result and writes storage before changing the scene. Object/draft limits and quota errors do not publish a partial batch; a quota failure can be retried from the same preview.
- Only inserted values become artwork. Unused columns stay out of saved projects; pasted rows exist only in the open panel. No network operation, new dependency, native bridge, project schema, search/ranking or billing change. Existing Excalidraw notices remain in place.
