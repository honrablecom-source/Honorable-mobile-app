## Privacy, ownership and storage

The independent `NobleCreative` module does not impersonate or replace search/account modules. Native search/ranking, permissions and the credit ledger are unchanged. The Android host serves only immutable bundled files from its private HTTPS origin, denies remote browsing, camera/microphone access and unrequested uploads, and accepts only explicitly selected local document URIs. Imports are bounded; exports stream to separate private cache files and request the system share sheet. Originals are not overwritten. A share handoff does not confirm saving, and the image engine retains its unsaved state for unconfirmed exports. Close warns before discarding work.

Personal-media limits remain128MiB per selected file/256MiB combined import and64MiB per export. The separately bounded executable-asset limit is96MiB to accommodate the real full image engine; this does not raise media/export limits. Local browser recovery, imported copies and shared export cache can remain after sign-out, disclosed in the UI. OPFS quota/process-death/recovery behavior still needs device acceptance.

## Source, builds and notices

The full source recipe, reviewed mobile patches, browser regression tests, packaging helper and dependency-notice collector live in `Honorable-mobile-app-main/mobile-react-native/full-editors/`. Original MIT/Apache and font notices are retained, including pinned root licenses omitted from some published crates, source links for MPL dependencies and Rust1.95 standard-library copyright notices. Bundles include273 video and292 image Cargo dependency notice records. Restricted ArtCraft logos were replaced with original Noble text/lettering. No proprietary Adobe/Photopea source is used.

Builds pin Rust1.95.0 and wasm-bindgen0.2.130(image)/0.2.129(video). The image build disables whole-program fat LTO after its final link was terminated; engine code remains optimized. The large UI crates use opt-level0/codegen-units256 to make these builds possible in this environment. These flags and the lockfile/source/patch hashes are recorded; mobile performance is unverified. Standalone compiler tools/caches are not committed. Generated executable assets and original legal notices keep exact bytes across checkouts.

Known platform limits remain: desktop thread-dependent FilmCraft previews/proxies/mask tracking are unsupported on the web; camera/microphone capture is denied by this host; PhotoCraft's optional HEIC/HEIF feature is not enabled in this build. A full engine contains operations that have not yet been tested on phones. There is no iOS native host for these two studios, and no new full-app APK/IPA/archive has been produced from this integration. Existing release artifacts do not contain later source. Private store signing, real-device behavior and store readiness are separate requirements.
