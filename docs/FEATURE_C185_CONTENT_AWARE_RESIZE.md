# C185 — Drawing-workspace extension of C136 (uncounted)

Extension of the existing C136 outcome: remove connected low-gradient seams along width or height, optionally exclude a rectangle of original pixels from every seam, review the complete PNG and insert a separate copy with Undo or hand off its exact bytes. **0 new source workflows.** C136 already provides content-aware narrowing in the native Library flow. This adds drawing-workspace access, horizontal reduction and original-pixel rectangle protection; platform copies and parameters do not count as new outcomes. Count this as one existing-workflow extension, not a new feature, separate legacy fix or scaffolding. No full native/APK build.

`photo-carve.mjs` validates 8–1024-pixel source dimensions, 1–128 removals, output ≥8 pixels on either axis, and source width × height × removals ≤8,388,608 as a conservative local-work bound. It privately copies original pixels and optional integer rectangle. A transpose gives the same specified algorithm for horizontal reduction. At every removal, luminance is recomputed from rounded-eight-bit source-over-white encoded RGB using weights 299/587/114. Energy is the sum of absolute left-right and up-down luminance differences, with edge coordinates clamped. Dynamic programming chooses a minimum-cost top-to-bottom connected seam; adjacent row positions differ by at most one. Ties choose the smaller predecessor coordinate, then smaller final coordinate. This is our pinned deterministic energy and edge convention, not a claim of reproducing another editor.

An original-index map follows each surviving pixel. Rectangle coordinates are original-grid, left/top inclusive and right/bottom exclusive. Its pixels have infinite removal cost. An impossible path, including protection exhausted by later removals, refuses the complete operation. Surviving raw RGBA values are copied without interpolation. Surrounding shapes and protected-pixel positions can still shift. No subject/face/text recognition, visual-quality promise, expansion or simultaneous two-axis optimization.

Concept reference: [Avidan and Shamir, Seam Carving for Content-Aware Image Resizing, MERL author publication](https://www.merl.com/publications/TR2007-087). Our implementation and independent exhaustive-path oracle are written for the contract above; no third-party source code copied.

`photo-carve-image.mjs` decodes the full embedded source before canvas crop/rotation/flip/opacity, checks dimensions and ownership, yields every 32 rows of energy/DP/compaction, and uses a shared 30-second deadline.
