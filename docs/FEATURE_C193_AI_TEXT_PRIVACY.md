## Bounded data and privacy behavior

`PhotoTextPrivacy.kt` captures immutable ≤1024×1024 opaque pixels with white alpha matte and canonical dimension/pixel SHA binding. Real boxes map outward with integer floor/ceil, clipping and stable deduplication.1–100regions, nonempty valid selection and0–24preview-pixel padding; merged row intervals become opaque black. Unselected normalized pixels remain exact. The core is deterministic raster work, not inference by itself; production geometry comes from the actual OCR result above.

PNG output is RGB8 with only IHDR/IDAT/IEND, under4,000,000bytes. It contains no OCR strings, original file bytes, recovery layers, EXIF or text metadata. A downscaled copy can lose detail; OCR can miss words and leave private content in unselected areas. The interface requires manual full-image review and promises no automatic all-sensitive-content protection or secure-redaction certification.

Controls own stage/current-owner checks, pause/destroy cleanup and their worker. Cancellation marks stale immediately while retaining input until an active/queued reader settles. Retained buttons cannot restart obsolete work. A fresh unchecked confirmation is needed for each proof. Sharing creates a uniquely named private cache PNG only after explicit Share, verifies length/SHA after writing and again immediately before handoff, and consumes the review once. Unshared files are deleted on cancellation/failure. Successfully shared files remain for recipients; cleanup on later use expires only this feature's files older than24h. Temporary storage permits8copies/32MB and refuses a ninth; peer-generated files are retained. A one-use review is not a one-use recipient URI.
