The older Timed captions menu and Add/Edit/Delete/Clear callbacks checked selected project/clip values inconsistently and did not carry a foreground generation. Paused/stale entry could construct Android UI, and a retained approval could become valid again after resume when the same values returned. These targeted dialogs now share an immutable review snapshot containing the full VideoCloseState, access mode/private namespace, lifecycle generation, all protected source URIs and original-source durations. Imported sources changing duration at the same URI also invalidate approval.

Entry requires foreground, idle, recovered editor state and the exact current selected clip. Manual cue indexes are checked before UI access. Every targeted menu action, edit apply, delete and clear approval rechecks the snapshot; caption mutations pass through one guarded existing project.setCaptions call. A value-equal reconstructed clip cannot substitute for the original target. Existing cue/source/project limits, one Undo/Redo, music and original subtitle-document protection remain. The Find captions → Jump and edit signature is preserved.

Tracked menu/manual/clear dialogs are removed from the set when dismissed. Pause/destroy increments the generation before dismissing the set, invalidating old callbacks even if values return unchanged after resume. This uses no worker, media/provider/network I/O, grant or clipboard operation. Existing report/search/copy dialogs outside this targeted family are not all migrated by this change.
