## Five-minute creative sequence

1. Cold-launch the self-contained APK without Metro. Choose **Edit without an account**, then **Advanced studios · preview → Image studio**. Confirm white/black mobile controls and readable errors. No account-backed search claim is made from this guest route.
2. Import the approved photo; make a visible layer edit and exercise Undo/Redo. Save a layered project, reopen it and verify the image/layers. Keep the original photo intact.
3. Open **AI photo tools → Use current document → Neural color & tone**. Run the actual local model. Compare the preview, adjust strength, verify approval is cleared, approve again and open a separate image document. Confirm the original layered document/history remain intact. Export a PNG copy, save to an actual destination and reopen it.
4. On the foreground fixture, run **Object cutout**. Show uncertain edges honestly, correct alpha with Erase/Restore and Undo, approve, and open a separate image. On the generated noisy fixture, run **Neural noise cleanup**; its working-copy limit is256pixels. Mosaic painting is a224pixel artistic transform. Do not describe either as full-resolution restoration.
5. Return to **Video studio**. Import the short approved clip or generated still, create a sequence, cut, Undo/Redo, save/reopen the project and export H.264. Reopen the exported file and check playback; test actual sound separately when audio is included.

If a tool fails, retain the source, display its error and demonstrate retry/Stop. Never present an old preview as the latest result. Do not hide model artifacts, cancellation problems or output-size limits during acceptance.

## Failure and recovery sequence

- Stop actual inference, switch tool, change source/strength, background the editor and close it while work is pending. A late result must never apply or share. Restart with explicit fresh review.
- Reject malformed/oversized input, corrupted model assets and unavailable export destinations without modifying the original project. Verify cancelled current-document snapshots never open native sharing.
- Save/reopen layered image and video projects after edits. Verify exported copies and source hashes. Test app termination/recovery, low memory, denied media access and storage failures on actual hardware when available.
- Check narrow-phone touch targets, screen-reader labels, focus, back navigation and keyboard behavior. Host browser width alone does not establish touch/accessibility acceptance.
