# C148 — Reviewed removal of repeated source footage

**1 new experimental source workflow; 0 separate fixes; 0 scaffolding. Registered after source verification.** Native video Project tools → Remove repeated footage prepares a complete remaining timeline by keeping the first timeline occurrence of each exact source-ID/source-millisecond range. Later overlaps are removed; a partly overlapping clip can split into several unique pieces. Entire duplicate clips disappear. Source order among retained pieces stays unchanged. The review lists every remaining source window, its original clip index and speed, changed/fully removed indices, old/new clip counts and precise playback durations before explicit Apply and preview.

This is a timeline edit, not file deletion, visual duplicate detection or URI alias matching. Different source IDs remain independent even if they refer to the same file. Intentional repeats are removed too; the review tells the user to cancel to preserve them. Existing C126 only inspects and navigates repeated footage, whereas this workflow constructs and commits a new timeline.

Whole untouched clips retain their existing values, including very short originals. New partial pieces must be at least0.1 playback second; a shorter unique remnant refuses the entire proposal rather than disappearing. The output limit is1000 clips. Coverage is unioned per source ID, so later duplicates of earlier discarded repeats cannot reappear. Exact integer source boundaries avoid a second playback-to-source rounding step; editing remains source-millisecond based, without codec frame-exact claims.

Partial copies keep appearance, speed, volume, title, source motion, caption URI/provenance and every intersecting caption with its original source timestamps. Outside captions are removed from that piece. Edge/audio fades repeat on new pieces. Caption/draft recovery limits are checked before any edit. Soundtrack settings remain unchanged and its selected excerpt restarts at the new timeline beginning; shortening footage changes music synchronization. The review says to preview/listen before export.

The existing owned batch-review path captures the project, source/account/foreground generation and soundtrack. The immutable complete proposal can apply once, only from its current dialog stage. Cancel/dismiss, stale/foreign/paused approval and failed application cannot revive it. Applying is one project change; Undo restores the original timeline and soundtrack, Redo restores the deduplicated edit. No media bytes are read/uploaded by the algorithm.
