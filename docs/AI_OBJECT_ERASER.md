# Local AI object eraser

Photo editor → Assist → AI object eraser reuses the official MIT MI-GAN end-to-end ONNX pipeline from [Picsart AI Research](https://github.com/Picsart-AI-Research/MI-GAN). Its graph includes crop/resize, preprocessing, neural reconstruction and postprocessing; this is actual pretrained inference, not a clone brush or preset. The [official upstream-linked conversion](https://huggingface.co/andraniksargsyan/migan) is pinned to revision406830d0fa60666da0071c342ad2fbc8f30c5c64,28079181bytes, SHA2566f1f3530a1a2324b19752018ce756088b07973cda8d7d890034ace5c8a48c40b. Full MIT license/provenance ship in assets/inpaint. No training, server, photo/query upload or model download is needed.

## Phone workflow implemented in source

The current complete edited photo is rendered into a separate working bitmap fitted within1024pixels; smaller images are not enlarged. Paint the object using a source-coordinate brush, change its radius or clear the selection. A percentage rectangle supplies a precise alternative. Letterboxing is excluded from the mask and multitouch stops painting. At least one pixel and at most75%of the working image may be selected; leave surrounding context visible.

MI-GAN reconstructs the selected area. Every unpainted working-image ARGB pixel is preserved exactly, including transparency. Painted pixels become opaque generated content. Full before/after images and fresh unchecked approval precede opening a separate PNG in the existing guest photo editor for further editing/save-copy export. Account-owned input requires separate unchecked consent to shared guest storage accessible after sign-out/account switching. Original media, current edit/history and protected-source references remain intact. The result is not an Undo action inside the original editor.

The controller retains its bitmap resources until its serial worker settles, cancels native inference through its own RunOptions and never closes the shared search environment. Source/scope/generation/edited-state/mask ownership is checked across preparation, inference and review. Private temporary PNGs are hash-checked before transfer and deleted on rejection, failure or stale ownership. Only a successful explicit handoff keeps the copy.

## Verified evidence and limits

Three portable model cases pass. The exact pinned production pipeline ran on the licensed public NASA astronaut fixture, changed7738painted pixels in a2.8s host observation, preserved every unpainted pixel and left source/mask arrays unchanged. This is a smoke check, not a quality or phone-performance benchmark.

Whole current PhotoEditorActivity plus depth/eraser helpers compile against actual AndroidAPI37/ORT1.20. Nine SDK34 native-graphics cases pass16.529s: complete preview/PNG pixels/fresh one-use approval, independent account consent, selection bounds, worker ownership/Stop, stale review, failed launch cleanup, letterboxed touch/defensive masks and actual Root entry with five ownership-change variants. An initial test-harness runtime classpath omitted existing PhotoComparisonFiles; corrected without changing assertions or production behavior. Mid-inference cancellation retains bitmaps until settlement; a modified prepared PNG is refused/deleted. Both additional cases pass. Combined regression with the three eraser model and five depth UI cases passes17/17in18.633s. Evidence is retained under .context/noble-main-inpaint.

The integrated UI uses an injected deterministic inference provider in SDK tests; actual neural inference was verified separately with production model code on the host. General object-removal quality, real Android JNI/UI/memory/thermal behavior, accessibility acceptance, device export and a current integrated APK remain unverified. MI-GAN can repeat textures or generate wrong shapes/seams and cannot recover the hidden original scene. iOS parity is not implemented. No renewed500-feature target or count.
