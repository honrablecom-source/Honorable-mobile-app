# C156 — Silence original clip audio over playback intervals

**1 new experimental source workflow; 0 separate product fixes; 0 product scaffolding. Registered after verified source checks.** Video Project → Silence playback ranges accepts pasted start/end intervals on the current edited-playback clock, reviews every resulting source window/volume and applies the source-audio edit once with one Undo. All original video source milliseconds, clip order and speeds stay. Original media is never changed, read or uploaded by the planner.

One to100 ranges, up to16000characters, accept nonnegative decimal seconds with up to three places. Increasing ranges must fit current playback; a final fractional playback millisecond can end at the rounded-up millisecond and is clipped to the actual project end. Overlapping/touching/duplicate requests merge. Each covered original-source window rounds outward to whole milliseconds to cover the requested source content, widening by less than1source millisecond perboundary (less than2playback milliseconds at slow speeds). Overlapping source envelopes merge again before splitting. Tiny positive source pieces are supported; no arbitrary minimum silently drops a requested short mute.

Only covered pieces of audible originals receive volume zero. Outside pieces keep their old volume. Already-muted originals remain intact without redundant splits. Whole-clip muting changes volume only, including retention of existing caption data outside the visible window. Partial pieces keep appearance, source motion, intersecting caption timestamps/URI/provenance and all other clip settings. A wholly already-muted request refuses as unchanged. Piece count1000, caption count/text/title and draft-recovery limits refuse the whole proposal before application.

**Soundtrack/voiceover audio is not muted. Captions remain readable, and originals retain all audio.** The input and full review explicitly disclose this scope; it is not privacy certification or a sample/frame-exact mute guarantee. Hard mute edges have no smoothing. Existing VIDEO and audio edge fades repeat on new pieces and can visibly change the edit. Motion stays source-anchored. Source splitting at1.5× can contract authoritative playback by up to1microsecond per added piece due to existing per-piece duration flooring; requested intervals refer to the edit before splitting. Both before/after duration and contraction are shown. Preview/listen before export.

The complete proposal reuses exact project/source/account/foreground generation and soundtrack bindings, visible dialog ownership, immutable one-use approval and normal project Undo/Redo. Cancel/dismiss/background/foreign/stale/paused approvals refuse; failed stale approval stays consumed after Undo. Input and full mapping clear with their stages. No automatic clipboard reads.
