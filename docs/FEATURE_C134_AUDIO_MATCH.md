# C134 — Match selected clip audio to a reference

Native video Titles & audio → Match clip audio level measures the selected clip and a different reference clip through the existing local original-audio decoder. It proposes one volume gain for the selected clip, reviews measured/predicted RMS and reference level, then applies through one Undo step. The reference, footage/timing/speed, captions, appearance, motion, other clips and soundtrack remain unchanged. Muted clips are refused rather than automatically unmuted.

Measurements use original source windows before fades, speed-processing differences or soundtrack/mix effects. The existing streaming decoder permits one readable audio track, at most two source minutes per range, bounded PCM buffers and a checked30second limit per decode. Cancel/background requests cooperative stop; blocked providers or native calls can delay return. Identical source/range measurements are reused when only clip gains differ. No media is uploaded, original written or new permission acquired.

Duration-weighted known-window RMS feeds the calculation. At least95% of source-time duration must be covered by known20ms energy windows. This is not95% raw sample completeness: the existing decoder marks a window known when sample density is within its85–115% expected-count policy (with the existing upper tolerance). Unknown windows are not silence. Both source RMS values and reference effective level must exceed0.001 (-60dBFS); unknown, nonfinite, silent/near-silent and stale source/window measurements are refused.

Reference target = reference source RMS × its current clip gain. Proposed gain = min(1, reference target / selected source RMS). This may lower gain or raise it within the existing0–1limit. The report explicitly discloses when that cap prevents reaching the target. Exact no-op proposals are refused. This is an approximate RMS guide, not LUFS/perceived-loudness normalization, final-mix analysis or a clipping guarantee. Fades, speed effects and soundtrack remain as configured; listen to preview before export.

The source/reference picker requires current visible inspector ownership and full session/source/project snapshot. Analysis owns the existing busy/cancellation slot and progress dialog; only its completion can release that slot. After release, full captured project/session/source/generation validation precedes cancellation/error messages and every result review. Stale/closed/foreign results cannot publish a proposal. Final tracked VideoBatchReview approval rechecks exact project identity and applies volume only once. Existing lifecycle cancellation handles pause/destroy. Failed/cancelled scans or invalid measurements leave gain unchanged. Real project Undo/Redo and durable codec paths retain annotations/provenance and soundtrack.
