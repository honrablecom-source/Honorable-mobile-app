# C124 — Caption translation worksheet

Native video Project tools → Caption translation worksheet opens a local keyed text table for all stored captions, including cues outside a trimmed clip's visible range. Users can edit it directly or explicitly copy the original worksheet, edit/translate elsewhere and paste it back. No translation service or upload is invoked. This provides per-cue text replacement across the project while retaining source timestamps, clip ordering/ranges/speed, subtitle provenance, appearance and soundtrack; it does not translate speech/audio or retime subtitles.

The first line contains a versioned SHA-256 identity derived from length-prefixed source IDs, clip ranges/speeds, subtitle-document provenance, cue counts, original timestamps and original text. The identity contains no source URI metadata in plaintext. Each remaining row is a numbered clip.cue key, a tab and escaped text. `\n` represents a line break and `\\` a literal backslash. The worksheet includes every original cue exactly once. Row order may change, but missing/duplicate/unknown keys, unsupported headers, stale originals/timing/source/provenance and malformed rows/escapes are refused together. This is an accidental/stale-input binding, not authentication or encryption. Unrelated look/title changes can retain the worksheet because only caption text is replaced; the current full session/project is still captured and guarded during review/apply.

Existing cue bounds apply: valid lossless Unicode,1–240 UTF-16 code units, up to3lines, no other controls, nonblank text and existing per-project count/UTF-8/recovery limits. Transfer is bounded to196000 UTF-8 bytes/characters before parsing. Unchanged imports are refused. Review shows every old/new text with its original-source timestamps and reports changed/total cue counts. Captions not changed retain their exact objects where possible; clips without changed cues retain their objects. No partial replacements are applied.

Copy original worksheet is a separate explicit button with a system-clipboard disclosure. Only that button writes the clipboard, with sensitive metadata requested. The tool never reads the clipboard programmatically; paste is an ordinary user editing action. It does not export media or source URI metadata. Another app or clipboard sync may access copied caption text. Cancel/dismiss clears input/review widgets; it does not clear the system clipboard or guarantee RAM erasure.

The existing tracked VideoBatchReview input/review stages enforce current visible dialog, request ownership and full foreground/session/source/generation guards. Exact project identity is rechecked before commit. The immutable one-use proposal applies through the actual project validator as one Undo step, preserving soundtrack; stale/hidden/foreign/paused approval cannot mutate it. Undo/Redo and durable codec recovery use existing production paths. No original media is written.
