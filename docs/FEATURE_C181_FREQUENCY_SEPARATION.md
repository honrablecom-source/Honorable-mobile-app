One new source workflow, registered at170/500: create an opaque blurred-base/encoded-detail PNG kit, edit copies, then recombine matching opaque layers in the same local tool. ## Explicit encoded-RGB contract

Full8–1024pixel source is used before drawing crop/rotation/flip/opacity. Split composites source alpha over white, rounding to8bits. The base is a square box blur with whole radius1–32pixels, clipped neighborhoods at source edges. It is not a Gaussian or ideal spectral cutoff. Three Uint32integral planes are bounded below2^32at1024square. Source alpha/hiddenRGB stay in the original; both generated layers are opaque.

For each channel, detail =clip(128+round((flattenedSource−base)/2),0,255). Recombine =clip(base+2×(detail−128),0,255). Neutral detail128 is exact. Exhaustive65536source/basepairs show unedited reconstruction error≤1eight-bit value/channel; errors after edits are intentional and unbounded by that original-source comparison. This is encoded-RGB math, without HDR/linear-light/color-management/external-editor blend-mode compatibility claims.

Split review includes both exact PNGs and a rawRGBA reconstruction guide/statistics. The guide is not a third saved layer. All-transparent input flattens to white explicitly. Recombine uses two full matching-size decoded photos, refuses any nonopaque pixel and allows swapping their roles. Generated role metadata prefers the corresponding partner automatically; arbitrary edited images can be selected manually. Distinct layer objects may share identical file bytes, including uniformneutral base/detail, so candidate selection does not deduplicate content IDs.

## Ownership and artifact behavior

Private input copies protect both operations. Split builds integrals then output buffers in32rowchunks, combine uses32rowchunks, with current checks through final yield. Decode/encoding owns an overall30second deadline and cleans canvas/handlers/listeners/timer on error/cancel. Every PNG must fit192KiB at the exact source grid; any split-part failure refuses the complete pair without resizing. Both BlobURLs revoke; settings/mode/partner/swap/hidden/Stop/Escape/unmount/source edits invalidate review.

Split atomically inserts two exact PNGs plus role labels as one4objectgroup/oneUndo. A role recipe records sourcefile/grid/radius/convention/recombination formula. Same-file layers retain distinct image objects and roles. Recombine inserts one independent exact PNG/oneUndo, with actual base/detailfile IDs and formula metadata. Existing photo/object/draft/storage limits stay. Original bytes/geometry are preserved; project recovery/JSON retain PNGs and recipes, SVG exports the rendered PNGs. Exact selected-layer handoff preserves reviewed bytes; subsequent edits/exports can change colors/size/alpha.
