# C088 — Copy full editable photo settings between originals

One new experimental source workflow, not two button features. Native photo inspector → **Editable project** now offers **Copy editable photo settings** and **Paste editable photo settings**. Existing named looks do not transfer the complete caption/object/region/layout edit; this workflow carries the whole portable PhotoEdit model to another original.

Copy reviews the inclusion of adjustments, crop, captions, objects and local regions, including hidden object text. It excludes photo pixels, original locations, account/session identity, Undo/Redo history, pending export and masks. The clipboard label is generic. The target editor must be foreground, idle and in its current valid source/session scope. Paste reads one compatible plain-text clipboard item only after the explicit action; it never resolves a URI/Intent or coerces HTML/provider content into text.

Paste decodes a prepared immutable edit, then reviews replacement. Approval binds the current dialog, original/model/history/pixel/source/scope/mode/protected originals/foreground generation and revision. Keep current/cancel, stale callbacks and pause/destroy keep the existing edit. Apply replaces settings through the same metadata commit used by existing editor changes and creates one Undo step; identical settings add none. Actual source/protected-original lists stay unchanged. Person masks are recomputed for the target on-device when necessary. Original pixels/saved projects remain separate, and session Undo is not a durable backup. Model application and preview availability are reported separately.

## Format and clipboard privacy

The canonical flat JSON envelope uses format noble.photo-settings, version1, canonical Base64 data and SHA256. Text is bounded to90,000bytes/characters; binary payload to the existing strict64KiB photo-session codec. A public constant scope deliberately removes source/account binding for this explicit transfer. Decoder checks forbid history, comparison/tool state and pending export in the payload. A fixed flat envelope avoids recursive untrusted JSON parsing, and unknown/future/extra/duplicate/noncanonical data fails closed. Digest detects alteration; it is not a signature or proof of authorship. This is Noble's format, not a claim of compatibility with another editor's settings schema.

Clipboard content includes caption/object text. Copy is explicitly reviewed and marks ClipDescription sensitive using Android's documented extra. [Android clipboard guidance](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste) describes this flag's visual-preview behavior. It does not encrypt the clipboard or prevent access/sync by the operating system or allowed apps. No auto clipboard clearing, background reads, content logging or direct network/media upload is added. Pasting settings the owner chose to copy is intentional metadata reuse across originals/accounts; actual clipboard service behavior remains platform-controlled.
