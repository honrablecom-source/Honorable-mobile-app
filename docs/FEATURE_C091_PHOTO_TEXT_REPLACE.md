# C091 — Reviewed replacement across editable photo text

One experimental source workflow: replace exact literal text across the current photo caption and eligible text objects, with a review and one Undo for the whole change. Previously these items were edited individually. This is one outcome, not separate counts for Find, Review, Replace or parameters.

Open **Photo inspector → Composition objects → Find / replace photo text**. Enter exact case-sensitive text and its replacement, then Review replacements. The bounded review lists occurrence/item totals, before/after text for the first six changed items, and how many additional changed items are included. Back returns to the form without changing edits. Confirm applies the whole prepared model through the existing metadata commit. Undo/Redo restores all text as one edit; source protection is retained. Longer text can require manual layout adjustment, which the review and completion notice explain.

Only the current editable caption and visible, nontransparent, unlocked text objects participate. Hidden, fully transparent and locked objects are preserved, with skipped occurrence counts; objects that are both locked and hidden count once as locked. Shape objects and repeated watermarks remain untouched. No OCR, bitmap/library search, regex, case folding, normalization, query logging or upload is introduced. Text shown in the form/review remains local app UI; keyboard/platform behavior is not verified by host tests.

Find must be nonblank; each input is bounded to 200 UTF16 units and at most three lines, with strict Unicode and control-character validation. Empty replacement is allowed only when each resulting text item remains nonblank. The actual caption limits (120 UTF16 units/360 UTF8 bytes), text-object 200-unit and three-line limits remain authoritative. Any invalid result rejects the entire preparation before committing edits; there is no truncation or partial application. The existing maximum 32 objects plus one caption bounds the work. Replacement is literal, case-sensitive and nonoverlapping.

The scrollable form and review share an owned controller. Exact controller identity, current full photo snapshot, source/session/access mode, foreground, generation, history and model reference must still match at commit. Busy/recovery/picker states refuse entry. Pause/destroy closes and clears the controller. Old Back/Replace/Cancel callbacks cannot close or apply a replacement review owned by a newer controller/token.
