# C128 — Replace video clip footage

Native video Picture tools → Replace clip footage selects a different source already added to the project, then a reviewed original-source start time. The replacement keeps the selected clip's source span, playback speed and exact playback duration. Title/title appearance, grade, framing/transforms, fades and source-audio volume settings stay. Audio now comes from the replacement source. Other clips and soundtrack remain unchanged.

Source-time captions, subtitle-document binding and source-anchored motion belong to the old footage. This workflow explicitly clears them on the selected clip rather than silently relabeling them onto unrelated footage. Input and final review disclose the caption count, cleared provenance/motion and retained settings. One Undo restores the original source window and all annotations. Old media/subtitle documents are never deleted or overwritten; the original source catalog stays registered and the existing Undo document-protection set retains old subtitle references.

The picker lists only different already-registered source IDs whose duration can contain the complete source span; exact-length sources are valid. Use the existing Add video control first if needed. Enter nonnegative decimal seconds with up to3decimals; the complete source window must fit. Unknown/same/short sources, invalid catalogs/original bounds and out-of-range starts are refused. Target duration minus source span bounds the addition before arithmetic. The proposal copies the selected clip with only source/window/annotation changes, checks authoritative whole-project microseconds are identical, and runs existing recovery validation. Applying uses the real project validator again. No automatic visual/semantic match or codec frame-exact cut is promised; preview before export.

Source choice, window input and final review use tracked VideoBatchReview stages. Each transition requires the current visible owner and full original project/source/session snapshot. Exact project identity is checked before one-use Apply. A stale/hidden/foreign/paused callback cannot replace a clip; dismissal clears the input. Successful or failed approval is consumed. No new source permission, file write, clipboard action, media upload or service is involved. The existing local editor loads/plays the replacement after Apply.
