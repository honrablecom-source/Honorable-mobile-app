# C132 — Combine bilingual caption tracks

Native video Titles & audio → Combine bilingual captions takes a pasted second-language SRT and the selected clip's existing first track. Both use original-source timestamps before speed changes. It flattens them into one editable caption list: existing text above second-track text during overlaps, available text during single-track spans, and no caption during empty gaps. It does not translate, infer language/speech or upload anything.

The pure merge partitions the union of all source cue boundaries. Each active pair becomes a validated caption; adjacent identical combined text is joined. Text present in both tracks is intentionally retained twice, even when words match. It preserves all parsed text and coverage or refuses the complete proposal. Existing240UTF-16-unit/three-line/nonblank/Unicode/control rules apply to every result. Final clip limit200, project count/UTF-8 text and durable-recovery limits apply before acceptance. A long or four-line overlap is refused rather than silently shortening either language. SRT input is bounded by existing128000-byte policy and explicit lossless Unicode conversion.

All stored cues participate, including those outside the current trim's visible range; the review discloses this. Source milliseconds are preserved and renderer speed mapping remains authoritative. Clip range, speed, appearance, motion, title/audio settings, existing subtitle-document binding and soundtrack stay. The second track is pasted text, so it introduces no external subtitle document or permission. The old document is never changed. The languages are no longer independently stored after applying; Undo restores the first track.

Input and final review use current visible VideoBatchReview stages and full session/source/project guards. Every result cue is shown with source timestamps, original/second/output counts and source-overlap milliseconds. Exact project identity is rechecked before one-use Apply. The existing project validator commits once; Undo/Redo restores complete state. Cancel/dismiss clears input/review text. No clipboard reads, provider probing or file writes are added; the existing preview/save-copy/export paths remain in use.
