# C154 — Explicitly relinked video cut-list import

**1 new experimental source workflow; 0 separate fixes; 0 scaffolding. Registered after verified source checks.** Video Project → Import video cut list accepts a pasted video-only C-cut EDL, an explicit reel-to-existing-source map and a chosen24/25/30 non-drop frame rate. Review every event's reel/source/frame/native-window/record mapping plus timing differences, then replace the timeline through owned one-use Apply and preview. One Undo restores the prior edit and soundtrack settings. No media or clipboard is read automatically; no original file is modified or uploaded.

This supports Noble's exported cut-list dialect and matching cut-only syntax, not arbitrary CMX effects. Source timecodes are zero-based from each original, not embedded camera timecodes. Reels must be explicitly linked to IDs already in the current source catalog; source-name/URI comments never relink files. Mappings can alias the same original deliberately. Events are consecutively numbered from001, with increasing equal source/record frame spans and contiguous record boundaries. Any initial record clock is normalized to program zero. Repeats and source-order changes remain exactly as listed. Single-frame cuts are supported rather than silently dropped.

The whole-millisecond source envelope rounds source-in down and source-out up, by less than1ms peredge. This preserves listed **source** frame codes on Noble's inward text re-export, while native playback duration can be longer than the record-frame duration. Both durations, difference and widened-event count are shown before Apply. Record clock origins are deliberately normalized, and aliases may receive a different reel assignment on later export. This is metadata planning, not a physical decoder/export frame-exact guarantee.

Imported clips are neutral1× windows with original camera audio at full volume. Old clip grades, layout, titles, captions/provenance, source motion, mutes and fades are not reconstructed: those fields are absent from this video-only interchange format. The input and review explicitly disclose their replacement. EDL audio tracks are not imported. Existing soundtrack settings/excerpt remain and start at the new timeline beginning, changing prior synchronization. Preview/listen before export.

Bounds:1–999events,1–32explicit reel links,128000UTF-8bytes of EDL and8192mappingbytes, valid zero-based source windows inside current original durations, valid24/25/30fps non-drop timecodes below24hours. Missing/duplicate/misplaced headers, mismatched declared Noble frame rate, unknown reels, invalid original catalogs, audio events, transitions, speed rows, unsupported non-comment lines, record gaps/overlaps/order/span mismatches and oversized/control-character input refuse the whole import. Comments are metadata only; unsupported non-comment edits are never silently ignored. An unchanged proposal is refused before review.

The complete immutable proposal reuses current project/source/account/foreground generation and soundtrack guards, current visible-stage ownership and one-use approval. Cancel/dismiss/background/foreign/stale/paused approvals refuse. A failed stale approval cannot revive after Undo. Input/reel/FPS text and full mapping clear when stages close.
