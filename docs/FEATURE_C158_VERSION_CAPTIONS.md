# C158 — Recover saved-version captions into current shots

**1 new experimental source workflow; 0 separate product fixes; 0 product scaffolding. Registered after verified source checks.** Saved video versions → Recover captions from a saved version prepares a caption-only merge into the current edit. Shots match by exact source ID/start/end window, independent of timeline position, speed or appearance. Review every old/new cue's source timestamps/text and subtitle-reference change before explicit Apply captions only. Current footage/order/speeds/volume/look/titles/motion/fades, soundtrack and selection/trim/playhead metadata remain. One timeline Undo restores prior captions; original documents and saved versions stay unchanged.

The existing private shelf binds the primary original/account scope. Primary duration must match; added originals require identical source IDs, URIs and duration metadata. This checks references/metadata, not media-byte fingerprints. A matching source ID alone cannot relink an added original. Unmatched current windows remain unchanged. Matching windows whose caption payload/reference already agrees remain unchanged and are counted separately. Empty saved captions clear current cues as explicitly shown. All saved source-time cues are copied, including cues outside the visible window; their playback uses current speed.

Several saved positions with the same source window are equivalent only when their complete captions and subtitle-document reference are identical. Conflicting saved candidates refuse the whole proposal. A unique payload can update several matching current occurrences; every changed current position is expanded. Saved-origin positions are grouped and listed once to avoid exploding review size for repeated cuts. Complete before/after text and changed subtitle-reference presence are shown; raw URI metadata is not displayed. Input/output lists and payloads are frozen before review. Caption count/text/title/reference, actual encoded draft size and1MB review limits refuse rather than truncate.

On approval the worker rereads the exact selected stored entry, recomputes the merge against the captured current snapshot and checks that the full proposed draft equals the reviewed one. Deleted/changed/foreign entries cannot substitute. Existing original/video/audio/subtitle access validation runs before applying. The existing shelf job, dialog-token/busy/session/namespace guards and Activity one-use shelf consumption remain unchanged. Cancel/background/owner/source/project changes or a retained old callback cannot use a dismissed review. Review text clears on dismissal. No automatic clipboard reads, saves, media copies or uploads occur.
