# C076 — Editable connected-color photo outlines

**1 new experimental source workflow; 1 separate browser-startup fix; 0 scaffolding.** This creates editable vector lines, distinct from C075's transparent raster copy. Seed, RGB tolerance and simplification are parameters of one workflow. No full app/APK build or device acceptance is claimed.

Objects → Trace connected outline lets a person tap a flat source-color region, preview its outside and inner contours, and insert grouped, closed, unfilled black line objects beside the source. Coordinate fields support keyboard/accessibility input. The new paths are selected for image export; Ungroup allows individual path editing. Keep original only cancels without mutation. Original and protected artwork, Undo/Redo, recovery, editable JSON, SVG and PNG exports are retained.

Tracing uses the full embedded source before object crop, rotation, flip or opacity. Four-connected RGB tolerance and transparent barriers match the shared C075 selector. Paths approximate source pixel centers rather than exact pixel-cell boundaries; simplification from 0–4 source pixels can change details. No photo pixels or fill enter the new line objects. Tiny/thin regions and complex traces are refused as a whole, rather than partially inserted. This is manual color selection, with local processing and no upload.

## Open-source reuse and safeguards

The already pinned [magic-wand-tool 1.1.7](https://github.com/Tamersoul/magic-wand-js) supplies MIT scanline selection, contour tracing and Douglas–Peucker simplification. Its existing full notice remains in `creation-web/THIRD_PARTY/MAGIC-WAND-LICENSE.txt` and the offline bundle. No new dependency is added. `selectConnectedColor` is shared with C075; its original 160-case independent BFS reference suite still passes, as does C075's actual browser flow.

Before contour allocation, the wrapper limits boundary complexity to 12,000 edges. It accepts up to 32 contours and 8,192 output points, checks finite in-source coordinates, closure and nondegenerate width/height, and refuses the entire result if any contour fails. Source dimensions remain bounded to 8–1024 px. Component and service fences check source/scene/editor/request lifetime; unmount suppresses late results. Selection/tracing/simplification are bounded synchronous library calls, so cancellation cannot interrupt their middle. Real-device latency remains unmeasured.

Insertion creates ordinary line elements and uses the existing scene preflight/object/byte checks before mutation. One Undo removes the whole trace. Existing photo bytes are neither changed nor duplicated. Ordinary layout autosave and explicit Save draft persist the result; unlike photo-copy publication, this does not promise a durable save before a vector scene update.
