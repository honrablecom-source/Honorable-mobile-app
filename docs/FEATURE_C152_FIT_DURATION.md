# C152 — Fit every shot to a shorter running time

**1 new experimental source workflow; 0 separate fixes; 0 scaffolding. Registered after verified source checks.** Video Project → Fit all shots to duration proposes centered source excerpts across the current timeline to meet a shorter requested playback duration while keeping every shot, its order and its speed. Review every old/new source window, speed, cue count and playback duration, plus requested/effective/minimum timing, before explicit Apply and preview. One Undo restores all original clip windows and soundtrack settings. Original media is never read or changed by this algorithm.

Available trimming capacity is weighted proportionally after reserving0.1 playback second for each newly trimmed piece. Whole originals already shorter than0.1second remain intact. Integer source-millisecond spans are allocated with exact overflow-safe proportional arithmetic; remaining playback budget is filled with available source ticks without exceeding the target. The final global shortfall is strictly below2milliseconds, regardless of clip count. At termination at least one source tick remains unallocated because the requested duration is below the original duration; its playback cost is at most2milliseconds, establishing the stated bound. This is source-time planning, not codec frame-exact export.

Targets must be positive, shorter than current playback and feasible while retaining every shot. No expansion, shot dropping or silently invalid tiny pieces. Target input accepts nonnegative decimal seconds with up to three places. Existing1–1000clip and supported source/timeline timing limits remain. BigInteger multiplication avoids overflow for very long valid timelines. Centering can differ by one source millisecond between opposite trimmed edges. There is no content/importance detection; the review explicitly tells the user to inspect every retained window.

Untouched clips retain their values. Trimmed copies preserve appearance, speed, volume, title, source motion, caption URI/provenance and intersecting source-time cues. Outside cues disappear only from the edited window. Motion keeps its original source anchors. Edge/audio fades repeat at newly trimmed edges. Soundtrack settings/excerpt remain and start at the shortened timeline beginning, changing prior music synchronization; preview/listen is required before export. Recovery/caption limits are checked before proposing changes.

The normal owned batch-review path captures exact current project/source/account/foreground generation and soundtrack bindings. The complete immutable proposal applies only once from its current visible stage. Cancel/dismiss/background/foreign/stale/paused approvals refuse; failed stale approval cannot become valid after Undo. Input and mapping text clear when stages close. No automatic clipboard reads or uploads.
