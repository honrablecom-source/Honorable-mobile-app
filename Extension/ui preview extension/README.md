# Current extension preview

Screenshots of the current reading experience:

- `automatic-highlights.png`: names highlighted in the novel automatically.
- `character-information.png`: character information beside the story.
- `place-information.png`: place information beside the story.

Open `index.html` for an interactive version using sample data. No popup is part of the current experience. The preview requires no API key or installation.

- `chapter-summary.png`: clicking the gold title opens the locally generated chapter summary.
- Character profiles also show power information and an editor for personal power/rank notes.
